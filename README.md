# Copilot API Portfolio

A showcase of integrations and automations built with the GitHub Copilot API.

## Overview

This portfolio demonstrates practical applications of the Copilot API to automate developer workflows, improve productivity, and create intelligent developer tools.

## Features

- **PR Summarization** - Automated generation of comprehensive pull request summaries
- **Code Review Automation** - Intelligent analysis and suggestions for code changes  
- **Architecture Querying** - Interactive exploration of repository structure and design patterns
- **Developer Workflow Automation** - Tools to streamline common development tasks

## Getting Started

### Prerequisites

- Node.js 16+
- GitHub Personal Access Token with Copilot API access
- Git

### Installation

```bash
npm install
cp .env.example .env
npm run setup
```
